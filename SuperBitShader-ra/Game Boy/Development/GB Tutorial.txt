----------------------------------------------------------------------
The Game Boy Hardware Explained
----------------------------------------------------------------------
1. The Game Boy is a handheld that uses 4 monochrome shades.

2. A real Game Boy Color screen has an input that looks different when processed through the Game Boy Colors Display, these color palettes are designed to match that output.

* To make these I made a palette and color corrected it with the GBC-Color shader, I then tweaked it and combined it with the Mixed-Frames for the final.

* To make it sure it was doable on real hardware I then re-created that Raw palette with in a 1.9 hue margin of error or less.

3. Also a real Game Boy has interframe blending for transparency, this effect is pre-baked into Super-Bit-Shader.
----------------------------------------------------------------------
How to Make your own Palette
----------------------------------------------------------------------
1. First open one of the included Mixed-Frames samples, in this tutorials case choose Sunset.
retroarch/shaders/SuperBitShader-ra/Game Boy/Development/Mixed Frames - Game Boy Color Palette/

2. Now with Sunset opened in Gimp you will see each color out of the palette labeled.
- W = White
- 1 = 2nd Lightest
- 2 = 3rd Lightest
- B = Black

3. Only adjust palette colors using the Mixed-Frames sample as a base as it would look dull when combined with "mixed_frames" otherwise.

4. Using Gimps "Select by Color Tool" with a threshold of 0.0 select W, 1, 2, or B.

5. Now using "Hue-Chroma" shift only their hue as you see fit.

6. With the first color done, now do the same to the remaining 3 until your satisfied with them.

7. If you want to go extra authentic I recommend trying to make a raw version of your palette then color correcting it with the GBC-Color shader inside of retroarch's image viewer. After that try to have the Mixed-Frames version match that result as close as possible.

----------------------------------------------------------------------
Importing the Palette into Retroarch
----------------------------------------------------------------------
1. Make a copy of "SBS - Game Boy (4-bit) - Sunset.glsl" in the following directory:
retroarch\shaders\SuperBitShader-ra\Game Boy\shader-files

2. Rename Sunset into your preferred palette name.
Example: "SBS - Game Boy (4-bit) - PaletteNameHERE.glsl

3. Open the file in a text editor, locate the "Palette Settings", then use the provided Hex to Vec3 converter to apply your colors.
https://airtightinteractive.com/util/hex-to-glsl/

3. Save the file and close it. Now it's time to change directories to the following:
retroarch\shaders\SuperBitShader-ra\Game Boy

4. Make a copy of "5. SBS - Game Boy Sunset.glslp" and rename it to your preferred palette name.
Example: "7. SBS - Game Boy PaletteNameHERE.glslp"

5. Open the GLSLP file in text editor and change Sunset to your palettes name as well.

----------------------------------------------------------------------
Testing the Palette
----------------------------------------------------------------------
1. Load any original Game Boy Homebrew like Fydo's Magic Tiles from Retroarch's TGB Dual / Double Cherry Core.

2. Access shaders from the Quick Menu and load your shader preset to test.

3. If it looks good, you are all set! :)
